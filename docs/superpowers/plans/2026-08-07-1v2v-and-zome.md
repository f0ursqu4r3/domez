# 1V/2V + Zome Mode Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expose 1V/2V geodesic frequencies and add a full-parity zome (polar zonohedron) mode — one strut length, rhombic panels, adjustable profile.

**Architecture:** Part A is UI-only (the engine already handles f=1..6; `Frequency` is already `1|…|8` in types.ts). Part B adds `src/engine/zome.ts` producing a standard `DomeModel` (rhombi as triangle pairs, real edges only, `rhombi` pairing metadata) via a `classifyModel()` helper extracted from `generateDome`; downstream systems consume it unchanged except panel takeoff (rhombus nesting) and mode-aware state/UI.

**Tech Stack:** Vue 3 + TypeScript, pure-TS engine, Three.js, vitest, bun.

**Spec:** `docs/superpowers/specs/2026-08-07-1v2v-and-zome-design.md`

## Global Constraints

- bun: tests `bunx vitest run src/engine/__tests__/engine.test.ts`, typecheck+build `bun run build`.
- Zome params: `sides` 4–16 default 8, `pitchDeg` 20–70 default 45, `rows` 1..sides−2.
- `baseMode` is shared between modes: zome natural = zigzag rim (1 strut type), zome leveled = filled rim (2 strut types). Riser eligibility is `baseMode === 'leveled'` in both modes (plus `fraction !== 'full'` for geodesic only).
- Zome count invariants (tests): natural V = 1 + n(R+1), E = n(2R+1), faces = 2nR, rhombi = nR; leveled V same, E = 2n(R+1), faces = 2nR + n.
- Geodesic behavior must be bit-identical when `mode === 'geodesic'` (all existing tests pass untouched).

```ts
import type { DomeModel, Edge, Face, Vertex } from './types'
import { classifyModel } from './classify'

export function generateZome(params: ZomeParams): DomeModel {
  const n = Math.max(4, Math.min(16, Math.round(params.sides)))
  const rows = Math.max(1, Math.min(n - 2, Math.round(params.rows)))
  const theta = (Math.max(20, Math.min(70, params.pitchDeg)) * Math.PI) / 180
  const leveled = params.baseMode === 'leveled'

  // Generators point down-and-out from the apex.
  const g = Array.from({ length: n }, (_, i) => {
    const phi = (2 * Math.PI * i) / n
    return [Math.sin(theta) * Math.cos(phi), Math.sin(theta) * Math.sin(phi), -Math.cos(theta)]
  })
  // v(k, i) = g_i + ... + g_{i+k-1}; apex v(0) at the origin. Rows planar.
  const vid = new Map<string, number>()
  const raw: [number, number, number][] = []
  const V = (k: number, i: number): number => {
    const ii = ((i % n) + n) % n
    const key = k === 0 ? '0' : `${k}:${ii}`
    let id = vid.get(key)
    if (id === undefined) {
      let x = 0, y = 0, z = 0
      for (let j = 0; j < k; j++) { const gv = g[(ii + j) % n]; x += gv[0]; y += gv[1]; z += gv[2] }
      id = raw.length
      vid.set(key, id)
      raw.push([x, y, z])
    }
    return id
  }
  // Rhombus band k (1..rows): corners T=v(k-1,i+1), A=v(k,i), Btm=v(k+1,i), B=v(k,i+1).
  // Split along the vertical diagonal T–Btm into (T, A, Btm) and (T, Btm, B).
  const rhombi: { vertexIds: [number, number, number, number]; faceIds: [number, number] }[] = []
  const triangles: [number, number, number][] = []
  const realPairs: [number, number][] = [] // rhombus perimeter edges
  for (let k = 1; k <= rows; k++) {
    for (let i = 0; i < n; i++) {
      const T = V(k - 1, i + 1), A = V(k, i), Btm = V(k + 1, i), B = V(k, i + 1)
      const f0 = triangles.length
      triangles.push([T, A, Btm], [T, Btm, B])
      rhombi.push({ vertexIds: [T, A, Btm, B], faceIds: [f0, f0 + 1] })
      realPairs.push([T, A], [A, Btm], [Btm, B], [B, T])
    }
  }
  // (Task 4 inserts the leveled half-band + base chords here.)
  ...build Vertex[]/Edge[]/Face[] (below), normalize, classify, return
}
```

Assembly mechanics (same file, continuing):

1. **Vertices:** `raw` → `Vertex[]` (`edgeIds: []`, `hubTypeId: -1`, `isBase: false`).
2. **Edges:** dedupe `realPairs` via `min:max` key → `Edge[]` (`chordFactor: 0` for now, `typeId: -1`, `faceIds: []`, `dihedralDeg: NaN`), push edge id into both vertices' `edgeIds`.
3. **Faces:** for each triangle, `Face` with `vertexIds`, `neighborIds: []`, and `edgeIds` = the subset of its three vertex pairs that exist in the edge map (2 for rhombus halves — the diagonal pair is absent; skip it). For every hit, push face id into `edge.faceIds`.
4. **Outward winding:** compute the solid's axis center `c = (0, 0, (zApex + zLow) / 2)`; for each triangle, if `dot(cross(b−a, c−a), centroid − center) < 0`, swap `vertexIds[1]` and `vertexIds[2]` **before** building faces (and keep the rhombus/faceIds mapping — the swap does not change face ids).
5. **Base flags:** after edges, every edge with `faceIds.length === 1` marks both vertices `isBase = true` (yields the zigzag rows R and R+1 naturally; leveled yields the flat ring in Task 4).
6. **Normalize:** `scale = 1 / max(hypot(x, y))` over kept vertices; also shift z so the **widest row** sits at z = 0 (find the row with max horizontal radius, subtract its z), then scale x/y/z uniformly. Positions become the canonical "unit" frame (world = position × radius, matching geodesic conventions).
7. **Chord factors:** `distance(v0, v1)` on normalized positions.
8. **Classify:** `const { strutTypes, hubTypes } = classifyModel(vertices, edges, faces)`.
9. **Return:**

```ts
const zLow = Math.min(...vertices.map((v) => v.position[2]))
const zHigh = Math.max(...vertices.map((v) => v.position[2]))
const baseRing = vertices.filter((v) => v.isBase)
return {
  params: { frequency: 1, fraction: 'full' }, // nominal; zome field is authoritative
  vertices, edges, faces, strutTypes, hubTypes,
  cutZ: zLow,
  actualFraction: rows / (n - 1),
  unitHeight: zHigh - zLow,
  unitBaseRadius: Math.max(...baseRing.map((v) => Math.hypot(v.position[0], v.position[1]))),
  rhombi,
  zome: { sides: n, pitchDeg: params.pitchDeg, rows, leveled },
}
```
